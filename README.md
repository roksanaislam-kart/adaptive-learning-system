# AI-Driven Adaptive Learning System for Personalised Exam Preparation

## Overview
This project presents the design and development of an AI-driven adaptive learning system aimed at improving personalised exam preparation.

The system analyses user interaction and performance data to dynamically adapt learning content, question difficulty, and personalised recommendations.

## Features
- User performance tracking
- Adaptive question difficulty
- Personalised topic recommendations
- Progress monitoring
- Mobile-based learning workflow

---

## Proposed Workflow
1. User attempts quiz questions
2. System tracks accuracy and response time
3. Performance is analysed
4. Adaptive engine adjusts learning difficulty
5. Personalised feedback and recommendations are generated
